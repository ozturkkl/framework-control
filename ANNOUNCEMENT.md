# What's new in 0.5.5

<div><video class="block mx-auto my-0" width=400 height=372 src="https://github.com/user-attachments/assets/ab34d70f-e233-4dd1-a1d2-8f2d921e3ef6" autoplay loop muted playsinline></video></div>

- **Customizable dashboard:** Drag panels into a different order, switch between full and half width, maximize, or hide them. Hiding a panel also disables its background feature.
- **Battery history:** Up to seven days of battery percentage and charge/discharge power, including a "Since last charge" view.
- **Per-fan calibration:** Multi-fan systems now get an individual duty-to-RPM calibration for each fan, and calibration waits longer for fans to stabilize.
- **New themes and visual overhaul:** A curated set of themes, improved panel layouts, cleaner graphs, and many responsive layout and accessibility fixes.

⚠️ **Existing fan calibrations need to be recorded again because calibration is now stored separately for each fan. You can re-run it from the Fan Control panel.**
